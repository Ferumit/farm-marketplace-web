# Фермерский маркетплейс — сайт, кабинет хозяйства и админка

Сайт платформы прямой продажи мяса: каталог, страницы хозяйств, оформление заказа с онлайн-оплатой,
кабинет хозяйства и административная панель. Без фреймворков — нативные ES-модули, один аккаунт
с мобильными приложениями, общая база.

## Что внутри

| | |
|---|---|
| `js/` | страницы и модули: каталог, лот, оформление, заказ, кабинет хозяйства, корзина |
| `admin/` | панель администратора: хозяйства, документы, споры, журнал действий |
| `css/` | оформление, светлая и тёмная темы |
| `deploy/` | конфигурация nginx: чистые адреса, заголовки безопасности, кэш |

## Что здесь интересного

**Ни одной зависимости во фронтенде.** Нативные ES-модули и Firebase SDK с CDN. Страница собирается
функциями, возвращающими строки HTML, — читается как шаблоны, но без сборщика и без шага компиляции.

**Один аккаунт на сайт и на приложение.** Вход по номеру телефона, анонимная сессия для каталога,
подтверждённая — для действий. Корзина, собранная до входа, переносится в аккаунт после.

**Конфигурация nginx с объяснениями.** Чистые адреса через `rewrite`, и в комментариях записано,
почему именно так: один раз `rewrite ... last` в паре с каноническим редиректом положил сайт
циклом, и разбор этой аварии лежит прямо в конфиге.

## Что убрано из этой копии

Репозиторий — публичная копия рабочего проекта. Из него вырезаны данные заказчика и всё
чувствительное: реквизиты юридического лица, телефоны и почта, идентификаторы проекта Firebase
и платёжного мерчанта, адреса серверов, боевые идентификаторы пользователей, доступы к онлайн-кассе,
внутренние планы и юридические документы. Ключи подписи приложений и файлы окружения в репозиторий
никогда не попадали — они под `.gitignore` с первого дня.

История коммитов не переносилась намеренно: один коммит вместо неё, чтобы ничто не уехало прошлым.
Поэтому проект **не собирается как есть** — нужны свои `google-services.json`, `firebase_options.dart`
и `.env` (рядом лежат файлы `.example`).

Права на код принадлежат заказчику. Выложено как портфолио.
